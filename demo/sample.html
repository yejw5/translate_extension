The first thing to notice about a translation layer is that it changes how you read. When the original and the translation sit side by side, you stop treating the target language as a replacement and start treating it as a hint.

This page exists only to exercise the extension: it contains headings, paragraphs, lists, tables, quotes, inline links such as this one, inline code_identifiers that must stay untouched, and a code block that should be skipped entirely.
